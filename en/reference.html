Commands of MacroTool

  • @ : define and set value of the macro variable
  • cin : input expression from console to macro variable
  • args : set default argument of the macro file
  • ++,– : increment(+1), decrement(-1) numerical macro variable
  • for,do,while,end : for, do, while loop
  • if,elif,else,fi : conditional branch
  • print : print arguments to console
  • fmt : set output format of macro variable
  • wait : wait time(sec) or console input
  • sys : execute system command
  • split : split string macro variable by specified delimiter
  • calc : evaluate the numerical expression
  • logic : evaluate the logical expression
  • q : quit the tip interpreter

Commands of drawing and handling data.

  • arc : draw a circle in the 2D-graph
  • box : draw the axis of the 2D-graph in the box shape
  • box3 : draw the axes of the 3D-graph
  • cat : show data contents / concatenate data
  • cut : set cut condition
  • div : divide the drawing area
  • elem : copy data element to macro variable
  • exe : execute macro file
  • fbox : draw a filled pattern box in the 2D-graph
  • ffit : fit the frequency domain graph
  • fit : fit the data in the 2D-graph
  • fit3 : fit the data in the 3D-graph
  • fill : draw a filled pattern object in the 2D-graph
  • font : set text font
  • fplot : plot the frequency domain graph from the data
  • getpos : get the position at the mouse cursor
  • help : show help message
  • hfit : fit the histogram
  • hplot : plot the histogram from the data
  • hplot2: plot the 2D-histogram from the couple of data
  • legend : draw a legend in the 2D-graph
  • line : draw a line in the 2D-graph
  • ls : list macro/data variables
  • mplot : plot the mesh-graph(3D) or contour-graph(2D)
  • mread : read the mesh data from the file
  • mset : set the mesh data
  • mwrite: write the mesh data to the file
  • order : set order of automatic graph attributes
  • opt : set/show global options
  • plot : plot the data in the 2D-graph
  • plot3 : plot the data in the 3D-graph
  • read : read the data from the file
  • rm : remove macro/data variables
  • set : define and set the value of data variable
  • sort : sort the data in ascending order
  • stat : calc statistics from the data
  • symb : draw a symbol in 2D-graph
  • text : draw a text in 2D-graph
  • title : set the graph title
  • tfmt : set the x-axis time format
  • vp : set viewport of drawing area
  • write : write the data to the file
  • xerr : plot the x-error-bars in 2D-graph
  • xlab : set the x-axis label
  • yerr : plot the y-error-bars in 2D-graph
  • ylab : set the y-axis label
  • zlab : set the z-axis label in 3D-graph

Commands of EPICS CA (option)

  • cainfo : show information of record
  • caget : get value of record
  • caput : put value of record
  • camon : open monitored record
  • cacheck: check if monitored record is updated
  • caclose: close monitored record
